Ticket System



A web-based Ticket System developed using Node.js, Express.js, MySQL, HTML, CSS, and JavaScript.



The system is designed to manage incidents/tickets through different user roles, providing separate interfaces and access levels for Administrators and Users.



Features



Authentication

\- User registration

\- User login

\- Password hashing using bcrypt

\- Role-based access control

\- Session/user information handling using browser storage



Admin Features

\- Admin dashboard

\- View and manage registered users

\- View and manage incidents

\- Monitor incident statuses

\- Separate admin navigation and dashboard interface



User Features

\- User dashboard

\- View incidents

\- Manage incidents

\- Track incident status

\- View user profile

\- Separate user navigation and dashboard interface



Incident Management

\- Create and manage incidents

\- View incident details

\- Track incident status

\- Admin and user-specific incident views
